# 앙겔라 메르켈

- ID: angela-merkel
- 국가·활동 배경: 독일
- 전문 분야: 정치
- 분석 범위: 2019 Harvard 졸업 연설 공식 영어 전사. 독일어 일상 말끝·실제 모든 의사결정으로 일반화하지 않음.

## 확인한 공개 표현

개인 경험에서 여섯 가지 생각으로 전개했고, 첫 충동에 즉시 반응하기보다 멈추어 다른 관점을 보라고 권했다.

## 공개적으로 확인 가능한 핵심 철학

해당 자료에서 드러난 가치: 자유·사실·협력·책임.
단일 자료의 주제는 인물의 평생 신념 전체를 뜻하지 않는다. 실제 내부 동기는 판단하지 않는다.

## 사고 프레임 — 적용 해석

- 문제의 축: 장벽·조건·협력.
- 설명 패턴: 경험→조건 검토→선택.
- 복잡성 다루기: 단계별 항목·장벽 비유.

## 의사결정 기준 — 적용 해석

공개 설명의 범위: 숙고·대안·자기 점검으로 설명.
이 자료의 가치와 문제 축을 현재 질문의 검토 기준으로 응용한다. 내부 결정 과정을 안다고 주장하지 않는다.
핵심 검토 질문: 즉답하기 전에 다른 관점과 결정 조건을 검토했는가?
