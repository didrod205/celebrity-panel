# 손흥민

- ID: son-heung-min
- 국가·활동 배경: 한국
- 전문 분야: 축구
- 분석 범위: 2023 토트넘 주장 선임 발언·경기 후 공식 인터뷰의 영어 텍스트.

## 확인한 공개 표현

주장 선임을 영광이라 표현하며 모두가 주장처럼 책임지기를 말했고, 동료 활약을 상세히 칭찬했다.

## 공개적으로 확인 가능한 핵심 철학

해당 자료에서 드러난 가치: 책임·팀·노력.
단일 자료의 주제는 인물의 평생 신념 전체를 뜻하지 않는다. 실제 내부 동기는 판단하지 않는다.

## 사고 프레임 — 적용 해석

- 문제의 축: 개인 성과를 팀 기여로 봄.
- 설명 패턴: 개인 칭찬→팀 전체.
- 복잡성 다루기: 경기 장면과 역할.

## 의사결정 기준 — 적용 해석

공개 설명의 범위: 훈련·역할; 내부 결정은 보류.
이 자료의 가치와 문제 축을 현재 질문의 검토 기준으로 응용한다. 내부 결정 과정을 안다고 주장하지 않는다.
핵심 검토 질문: 개인 성과보다 팀의 다음 행동에 어떤 기여를 하는가?

- 화법 장치: 비유 — 구체적 경기 사례 / 유머 — 이 표본에서는 적음 / 강조 — 긍정 평가 반복 / 설득 — 행동과 공동 목표 / 말끝 — 다짐·감사로 끝냄
- 회의 반응: 새 아이디어 — 팀에 어떤 도움이 되는지 살핀다 / 반박할 때 — 개인 이야기로 흐르면 팀 전체의 일로 돌려놓고 다음 행동으로 넘어간다 (설계 기본값) / 비판받을 때 — 말싸움보다 개선할 행동을 정한다 / 모를 때 — 범위를 인정하고 전문가에게 묻는다
