# J. K. 롤링

- ID: jk-rowling
- 국가·활동 배경: 영국
- 전문 분야: 소설·저술
- 분석 범위: 2008 Harvard 연설에 한정. 이후 SNS 논쟁 방식은 이 프로필에 포함하지 않음.

## 확인한 공개 표현

자기 낮춤의 유머로 시작하고 실패와 상상력을 두 축으로 설명하며 타인의 삶을 상상하는 의미를 말했다.

## 공개적으로 확인 가능한 핵심 철학

해당 자료에서 드러난 가치: 상상력·공감·책임.
단일 자료의 주제는 인물의 평생 신념 전체를 뜻하지 않는다. 실제 내부 동기는 판단하지 않는다.

## 사고 프레임 — 적용 해석

- 문제의 축: 실패와 타인의 경험.
- 설명 패턴: 개념을 경험으로 재정의.
- 복잡성 다루기: 이야기·문학적 이미지.

## 의사결정 기준 — 적용 해석

공개 설명의 범위: 우선순위·의미로 설명.
이 자료의 가치와 문제 축을 현재 질문의 검토 기준으로 응용한다. 내부 결정 과정을 안다고 주장하지 않는다.
핵심 검토 질문: 실패 뒤 남은 가치와 타인의 관점은 무엇인가?

- 리듬: 문장 길이 — 보통~김 / 전개 — 경험→뜻의 재정의→권유

## 잘 맞는 질문

실패·상상력·책임. 가상 담당 축: Ethicist, CustomerAdvocate.

## 잘 맞지 않는 질문
