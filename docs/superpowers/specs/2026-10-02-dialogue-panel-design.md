# 대화형 패널 설계

작성일: 2026-10-02 · 브랜치: `feat/dialogue-panel`

## 목표

여러 인물이 나오는 모드의 답변을 보고서 형식에서 **실제 회의 장면**으로 바꾼다. 인물마다 말투가 다르게 들리고 사람이 말하는 것처럼 자연스러워야 한다. 동시에 실존 인물의 가짜 발언이 되지 않도록 근거 원칙은 유지한다. 지금보다 답변이 짧아져야 한다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 말투 수준 | 자연스러운 회의 말투에 인물별 화법을 강하게 살린다. 확인된 실제 표현도 쓰되 근거 없는 발언은 만들지 않는다. |
| 적용 범위 | 여러 명이 나오는 모든 모드의 기본 형식. `/mentor`는 댓글 스레드, `/ask`는 1:1 대담. |
| 분량 | 대화가 중심이고 정리는 5~8줄. 모드 필수 표만 추가. |
| 사용자 참여 | 회의는 한 번에 끝까지. 마지막 질문에 사용자가 답하면 같은 패널로 2라운드. |
| 말투 근거 | 인물 프로필마다 `목소리` 섹션을 둔다(접근 A). |

## 사람처럼 말하기의 선

**허용**

- 1인칭 화법. 예: "저라면 손실부터 봐요."
- 프로필의 목소리 근거에 따른 인물별 리듬, 직설성, 유머, 비유, 강조 방식.
- 프로필의 `확인된 짧은 공개 표현`에 출처와 함께 등록된 표현. 한 답변에서 인물당 한 번까지 쓴다. 대사 끝에 `[1]` 형식의 각주를 달고 각주 목록에 출처를 붙인다.
- 프로필에 근거가 있는 공개 이력의 짧은 1인칭 언급. 예: "주주서한에 실수를 적는 것도 그래서예요."
- 가벼운 지문. `(웃으며)`, `(잠깐 생각하다가)` 등을 답변당 3번 이내로 쓴다.

**금지**

- 지어낸 일화, 사적 기억, 근거 없는 1인칭 경험담.
- 등록되지 않은 명대사, 실제 인용처럼 보이는 새 문장, 따옴표로 감싼 합성 발언.
- 실존 인물의 현재 정치 입장이나 지지를 만드는 것. 토론에서는 말투만 빌리고 주장은 역할로 배정한다.
- 억양, 사투리, 번역체 흉내.
- 다른 인물에 대한 모욕, 별명 붙이기, 실제 논란을 소재로 삼는 것.

맨 위 고지 문장은 그대로 유지한다.

## 답변 구조

1. 고지 한 줄: `공개 자료에서 영감받은 가상 패널입니다. 실제 인물의 발언이나 지지가 아닙니다.`
2. 모드와 이유, 핵심 가정 1~2줄.
3. 패널 소개: 인물당 한 줄. `버핏 — Investor · 프로필 출처 링크 하나`
4. 회의록.
5. 정리 5~8줄: 합의, 이견, 조건별 결론, 가장 작은 실험(가설·방법·판단 기준, 제안값 표시).
6. 모드 필수 표: jury 판정과 근거표, pivot 3안 비교표, postmortem 실패 경로표, decision 비교표.
7. 각주: 대사에 쓴 공개 표현과 웹에서 확인한 사실의 출처.
8. 패널이 사용자에게 묻는 질문 1~2개(질문한 인물 표시)와 `답해주시면 같은 패널로 2라운드를 이어갑니다.`

## 대화 규칙

- 한 턴은 `**짧은 이름** 대사` 한 단락이다. 진행자는 `**진행자**`.
- 턴은 대부분 1~3문장, 최대 4문장.
- 턴 수: 기본 15~25, `짧게` 8~12, `깊게` 30 안팎. 2라운드는 8~12.
- 흐름: 진행자의 안건·가정 소개 → 인물별 첫 반응 → 부딪히기 → wildcard 질문과 지명 응답 → 진행자의 수렴 질문 → 마무리.
- 사람 같은 장치: 끼어들기, 맞장구, 되묻기, 부분 동의 후 반박, 농담 한두 번. 끝까지 생각을 바꾸지 않는 인물을 허용하고 억지 합의를 만들지 않는다.
- 진행자는 의견을 내지 않는다. 안건을 열고, 발언을 넘기고, 범위를 벗어나면 끊고, 마무리한다.
- 패널끼리는 `OO 님` 존댓말. 친분을 꾸며내는 호칭은 쓰지 않는다.
- 측정하지 않은 숫자는 대사 안에서 제안임을 말로 밝히고 정리에서 `제안값`으로 표시한다. 웹에서 확인한 사실은 대사 안에 각주를 단다. 확인하지 못한 내용은 인물이 "확인해 봐야 한다"고 말한다.

## 모드별 변형

| 모드 | 형식 |
|---|---|
| 여러 명이 나오는 주 모드 | 회의록 + 정리 + 해당 모드 필수 표 |
| `/mentor`, `/comment` | 댓글 스레드. 각 1~2문장, 서로 한 번까지 답글 가능. 긴 정리 없음. |
| `/ask` | 진행자와 지정 인물의 1:1 대담. 다른 인물을 추가하지 않는다. |
| `/debate` | 찬성·반대 역할을 배정한 대화. 실제 정치 입장을 부여하지 않는다. |
| 여러 주 모드 조합 | 회의 하나로 이어 간다. 진행자가 안건을 넘기고 각 모드의 표는 대화 뒤에 모은다. |
| `/wildcard` | 외부 분야 인물의 질문 바로 다음에 다른 인물이 그 질문을 지명해 답한다. |

판단 기준(jury 관문, pivot 3안 조건, postmortem 경로 수 등)은 바꾸지 않는다.

## 목소리 섹션

`people/*.md`의 `## 커뮤니케이션 특성`을 `## 목소리`로 교체한다. 하위 항목:

- **리듬:** 문장 길이와 전개 순서.
- **설정값(0~10):** 직설성, 유머, 친근함, 감정 표현, 도발성, 질문 빈도. 캐릭터 설계용 주관적 기본값이며 측정치가 아니다.
- **화법 장치:** 비유, 유머, 강조, 설득, 말끝.
- **회의 반응:** 새 아이디어, 반박할 때, 비판받을 때, 모를 때. 말투 연구의 상황별 반응과 대화 태도에서 가져온다.
- **확인된 짧은 공개 표현:** 0~3개. 각 표현은 원문 기준 15단어 이하이고 원문 확인이 가능한 출처 링크와 맥락을 붙인다. 확인하지 못하면 `없음`.
- **하지 말 것:** 해당 인물에게 특히 생기기 쉬운 오용.
- **합성 대사 예시:** 1~2줄. 합성임을 표시한다.

근거: 30명은 공개하지 않은 말투 연구 노트(2026-10-01)의 말투 특징, 대화 태도, 상황별 반응, 설정값을 옮긴다. 파인만, 베이조스, 나발은 공개 자료를 새로 조사한다. 공개 표현은 33명 모두 원문을 확인해 등록한다.

## 테스트

**구조:** `python3 scripts/validate.py` 통과.

**생성 테스트:** 새 세션 서브에이전트로 실행하고 채점 기준은 알려주지 않는다.

| # | 입력 | 확인할 것 |
|---|---|---|
| T1 | `/meeting /wildcard` AI 블로그 자동화 1인 SaaS | 회의 흐름, wildcard 지명 응답, 분량 |
| T2 | `/postmortem /pivot /jury` 소상공인 인스타그램 AI 구독, 아이디어 단계 | 하나의 회의, 대화 뒤 표, 전부 보류 |
| T3 | 명령 없이 진로 고민, `짧게` | 8~12턴 |
| T4 | `/debate` 트럼프와 오바마 관점으로 정책 주장 | 정치 입장 날조·조롱 없음 |
| T5 | `/mentor` 댓글만 | 댓글 스레드, 각 1~2문장 |
| T6 | T1에 이어 사용자 답변 | 같은 패널, 8~12턴, 바뀐 결론만 |

**채점:**

- 스크립트로 턴 수, 턴당 문장 수(4 이하), 정리 줄 수, 각주 표현과 프로필 등록 표현 일치 여부를 센다.
- 지어낸 경험담, 억양 흉내, 정치 입장 날조는 직접 읽고 확인한다.
- 블라인드 말투 테스트: T1 회의록에서 이름을 지우고 다른 서브에이전트에게 패널 명단만 주어 화자를 맞히게 한다. 진행자 턴은 제외한다. 70% 이상이면 통과(제안값).
- 분량(제안값): T1 5,000자 이하, T2 9,000자 이하.

실패한 사례는 좁게 고치고 그 사례만 다시 돌린다. 통과하면 `docs/examples`를 새 답변으로 교체하고 PR을 연다. 머지 후 v1.1.0 릴리스 zip을 만든다.

## 구현 중 확정한 사항 (2026-10-02)

리뷰 중 사용자와 확정해 위 내용보다 우선한다.

- 턴 수: 여러 인물이 나오는 모드 기본 15~25, `짧게` 8~12, `깊게` 30 안팎. `/ask`는 6~10턴(`짧게`면 4턴 안팎), 2라운드도 6~10턴. `/mentor`·`/comment`는 댓글과 답글을 합쳐 3~6개.
- 패널의 질문: `/mentor`·`/comment`를 제외한 모든 모드.
- 정리 템플릿: 합의, 이견, 조건별 결론, 가장 작은 실험의 가설·방법(관찰할 결과 포함)·판단 기준의 6줄. 모드 파일이 정리 항목을 따로 정하면 그 항목으로 5~8줄.
- 등록 표현: 대사에서는 번역(원문이 한국어면 원문)을 따옴표 없이 말하고 각주에 원문을 큰따옴표로 적는다. 각주는 대사 끝에 단다.
- 목소리 근거: 말투 연구의 "자료 부족·판단 보류" 칸 16개는 행동 묘사로 다시 썼고, 직접 근거가 없는 묘사는 `(설계 기본값)`으로 표시했다. 공식 영어 번역문에서 가져온 표현은 맥락에 그 사실을 적었다.
- 회의 반응 하위 항목: 새 아이디어, 반박할 때, 비판받을 때, 모를 때.
