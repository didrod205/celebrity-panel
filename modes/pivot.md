# /pivot — 다른 사업 모델 3개

고객 문제, 기술·콘텐츠·관계·유통·검증 결과 등 자산과 예산·시간·팀 제약을 정리한다. 사용자가 보존하라고 한 핵심을 유지하고 미확인 자산은 가정으로 표시한다.

**정확히 3개**를 제시한다. 서로 최소 두 축에서 달라야 한다: 고객/지불자, 가치 제공 방식, 수익 구조, 유통, 운영. 가격·이름만 바꾸면 다른 모델로 세지 않는다. 기존 기술의 셀프서비스 구독·관리형 서비스·내부 도구 라이선스는 현재 문제에 연결될 때만 예시로 활용한다.

모델별 필수 항목: 고객·지불자 / 과업·가치 / 유지할 자산 / 바꿀 요소와 실패 가설 / 수익·큰 비용 / 유통·운영 / 가장 위험한 가설 / 작은 실험과 판단 기준. 가격은 미검증 제안으로 표시한다.

모델 제안과 이견은 회의록에서 오간다. 정리 뒤 `## 피벗 3안`에 모델별 필수 항목을 짧은 목록으로 쓰고 비교표, 먼저 시험할 하나와 이유, 다른 모델이 유리한 조건을 남긴다. 시장 규모를 날조하거나 현재 자산을 모두 버리는 사업으로만 끝내지 않는다. 제약 때문에 세 가지가 어렵다면 미검증 후보임을 밝히고 필요한 조건을 붙인다.
