# Idea Expansion — 아이디어 발전

아이디어 한 줄을 목표 고객·과업·가치의 가설로 바꾼다. 구체적 사용 장면, 제품·UX·수익·마케팅·기술·공유 확산 중 필요한 축을 나눈다.

패널마다 다른 발전 방향과 이유를 제안하고 가장 유망한 요소를 하나의 서비스 콘셉트로 조합한다. 기능 목록만 늘리거나 모든 고객을 동시에 겨냥하지 않는다.

결과: 한 문장 콘셉트 / 최초 고객 / 핵심 사용 흐름 / 최소 제공 가치 / 수익 가설 / 제외할 기능 / 작은 실험. 숫자는 제안값이다. 완전히 다른 사업 모델을 세 개 비교하려면 pivot을 사용한다.
