# Celebrity Board Meeting — 아이디어 회의

목표 고객, 해결할 과업, 현재 단계와 제약을 확인한다. 역할이 다른 3~5명을 선정한다.

1. 첫 반응: 각자 한 가지 가치와 가장 큰 질문.
2. 상호 토론: 다른 패널의 구체적인 주장에 동의·반박하고 이유·조건을 붙인다. 기본 한 차례, 깊은 요청이면 추가 검토.
3. 핵심 쟁점: 비슷한 증상을 묶고 가치·실행·경제성의 차이를 구별.
4. 개선안: 쟁점과 연결되는 수정.
5. 결론: 유지 / 버림 / 수정 / 검증할 가설 / 첫 실험.

빈 찬반 투표로 끝내지 않는다. wildcard가 있으면 다른 패널이 외부 분야 질문에 응답하고 바뀐 판단을 정리에 반영한다.
