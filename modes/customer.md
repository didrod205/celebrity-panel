# Customer Simulation — 고객 관점

특정 고객 유형을 합성 역할로 구성한다. 없으면 과업과 환경이 다른 소수 유형을 가정하고 표시한다. 유명인은 전략 프레임, 고객은 사용 맥락 검토를 맡는다.

과업 / 현재 대안 / 도입 마찰 / 시간·돈 / 신뢰 / 다시 쓸 계기 / 지불을 거절할 이유를 검토한다. 인구학적 고정관념으로 반응을 만들지 않는다.

결과: 고객별 예상 반응 가설, 가장 큰 장벽, 실제 인터뷰 질문, 관찰할 행동. 시뮬레이션은 실제 인터뷰·수요·전환율·지불 의사 증거가 아니다. 출력하는 고객 역할도 총원에 포함한다.
