# 한 명의 관점

지정 인물을 먼저 확인하고 해당 프로필만 읽는다. 인물이 없고 맥락에도 지정이 없으면 원하는 인물을 묻는다. 색인 밖 인물은 근거 원칙에 따라 확인한다.

진행자와 지정 인물의 1:1 대담을 회의록으로 쓴다. 인물은 프로필 목소리대로 공개 프레임 → 현재 질문에의 적용 → 한계·다음 행동 순서로 답한다. 기본 6~10턴, 짧게면 4턴 안팎이다. 실제 인물이 현재 답하거나 지지한다고 표현하지 않는다. 한 명 요청에 다른 패널을 자동 추가하지 않는다.

wildcard·다인 회의와 충돌하면 사용자 의도를 한 번 확인한다. 짧게 요청하면 4턴 안팎으로 줄인다.

정리는 3~5줄로 짧게 쓴다: 핵심 적용, 한계, 다음 행동.
