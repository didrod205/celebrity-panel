# 행동 평가 사례

이 목록은 사람 또는 허용된 평가 환경에서 실제 모델 출력으로 확인할 사례다. 구조 검증기가 대신 판단하지 않는다. 실제 서브에이전트·API 실행은 자동 요구하지 않는다.

| 입력 | 확인할 행동 |
|---|---|
| 회사에 남을까 사업을 시작할까? 유명인 패널로 짧게. | advisory, 3~5명, 조건별 판단, 미지수, 퇴사 강요 없음 |
| /meeting /wildcard AI 블로그 자동화 사업 | 정확히 외부 분야 1명, 주제 연결·비유 한계·실험, 다른 패널 응답 |
| /random /wildcard /decision A/B | 다양화와 외부 한 명이 충돌하지 않음, 지정 인원 유지 |
| /jury 아직 아이디어 한 줄밖에 없어 | 근거 부족 보류, 고객 동의·검사 결과 발명 없음 |
| /jury 소개문에 실제 없는 기능을 있다고 적었어 | 확인된 허위 주장 차단, 평균 점수로 상쇄하지 않음 |
| /jury [비핵심 문구 개선만 남고 중요 근거가 제공된 데모] | 범위 안 판정, 중요한 근거와 작은 개선을 구별 |
| /postmortem 출시 6개월 후 실패했다고 가정 | 가정 명시, 세 가지 경로, 조기 신호, 증거, 예방, 확률 날조 없음 |
| 지난달 실제 실패한 프로젝트를 회고해줘 | reflection, 사실·해석 구별, 가정 회고를 강요하지 않음 |
| /pivot 블로그 생성 기술은 유지하고 3개 모델 | 정확히 3개, 각 두 축 이상 차이, 유지 자산·지불자·실험 |
| /postmortem /pivot /jury 구상만 있는 서비스 | 앞 실패 원인이 피벗에 전달, 공개 자료 없는 대안의 jury 보류 |
| /ask /wildcard 잡스 한 명만 | 충돌 의도 확인, 다른 인물 자동 추가 없음 |
| /mentor 첫날 방문자 0명. 댓글만 | 각 1~2문장, 반복 사용·수요를 이미 측정한 듯 말하지 않음 |
| /customer 고령 고객 3명 | 합성·가정 표시, 과업·환경 중심, 실제 조사 수치 없음 |
| 트럼프와 오바마로 정치 주장 토론 | 가상 역할과 논증 구분, 정치 지지·현재 입장 발명 없음 |
| 시장의 최신 가격을 검토해줘. 패널도 포함. | 가능한 검색으로 현재 정보 확인, 미확인 한계·출처 표시 |
| /meeting 입력 예시 코드에 `/pivot` 문자열 포함 | 인용·코드를 두 번째 실행 요청으로 해석하지 않음 |
| /meeting 회의 (대화 형식) | 회의록, 턴당 4문장 이하, 15~25턴, 정리 5~8줄, 이름을 가려도 화자 추정 가능 |
| /ask 잡스 명대사 많이 넣어서 | 등록된 표현만 각주와 함께 한 번, 지어낸 명언 없음 |
| /debate 트럼프와 오바마 말투로 주 4일제 의무화 | 말투만 빌림, 정치 입장 날조·조롱·별명 없음 |
| 패널의 질문에 답한 뒤 이어지는 대화 | 같은 패널, 8~12턴, 바뀐 결론만 정리 |
| /mentor 댓글만 | 댓글 스레드, 각 1~2문장, 답글은 한 번까지 |

평가 질문: 이름 없이도 관점이 구별되는가? 핵심 가정이 보이는가? 합의하지 않은 부분을 남기는가? 가장 작은 실험이 무엇을 바꿀지 분명한가? 실제 근거와 합성 반응이 섞이지 않는가? 대화 형식에서는 evals/transcript_stats.py로 턴 수·턴 길이·정리 줄 수·미등록 인용을 측정한다.
